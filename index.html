SCHRITT 05 · UNABHÄNGIGER GEGENCHECK
Linux Live-Test
Ubuntu lässt sich vom USB-3.0-Stick ausprobieren. So prüfen wir GPU-Erkennung und Linux-Treiber unabhängig von der vorhandenen Windows-Installation.

          
Wichtig: Linux kann ein Windows-Problem stützen, aber ein fehlender Controller unter Linux beweist keinen Defekt. RGB-Unterstützung und I²C-Zugriff sind je nach Kernel und Software unterschiedlich.

          
VORBEREITUNG
Live-USB erstellen
  1. Ubuntu Desktop (offizielle ISO) herunterladen.
  2. Rufus (offiziell) öffnen und den USB-Stick als Ziel auswählen. Der Stick wird gelöscht.
  3. ISO schreiben und am MSI-PC über F11 den USB-Stick booten.
  4. Ubuntu ausprobieren auswählen, nicht installieren. Secure Boot nur nach Prüfung einer möglichen Windows-Geräteverschlüsselung ändern.

          
Hardware unter Linux nur auslesen
Terminal öffnen (Strg + Alt + T), folgenden Block einfügen. Er prüft Kernel, PCI-Geräte und vorhandene I²C-Gerätedateien ohne Registerscan und ohne Änderungen.
